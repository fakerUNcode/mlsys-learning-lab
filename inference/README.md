# 推理基础验证

本模块用于模型执行、KV Cache、资源估算与计时定义的小型验证实验。当前状态以本目录内的代码和报告为准；公开模型集成、优化 runner 和低精度评测尚未形成完整实现。

当前仅有文档约定，尚无模型 runner。第 5～8 周建立主项目公开模型 baseline，本仓库同步保留简化缓存与前向数值实验。

## 基础验证要求

- 固定输入比较有/无 KV Cache 的下一 token logits，明确误差容忍。
- 区分 prefill、已有缓存的 decode 与固定长度生成。
- 用维度、dtype、层数与 KV head 数估算权重/激活/缓存容量，再验证。
- 记录设备、模型/输入版本、warmup、计时边界、随机种子和原始结果。
- 不将离线生成测量写成在线服务并发或尾延迟结论。

每个实验有 reference、测试、运行命令和自己的解释；真实模型报告不在两个仓库重复维护。旧学习记录与相关教程保持原路径。
