# 学习入口

这里是项目唯一的阶段学习入口。阶段目录统一使用两位数字，避免资料散落。

```text
learning/
├── stage-00/
│   └── before-learning/   # 已有环境与 CUDA 资料导航
└── stage-01/
    ├── before-learning/   # C++ 与 Linux Runtime 前置讲解
    ├── examples/          # 可编译程序
    └── exercises/         # 待作答练习，不含答案
```

## 学习顺序

1. [主线指南](../Infra%20Introduction.md)：完整 Infra 能力链与验收标准。
2. [阶段0](stage-00/README.md)：环境、工具和已有 CUDA 笔记。
3. [阶段1](stage-01/README.md)：C++ 与 Linux Runtime，当前阶段。

旧资料暂不搬动，只在阶段目录中建立索引。这样已有链接仍然有效，新增资料也有固定入口。
