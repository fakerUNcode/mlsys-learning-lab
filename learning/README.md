# 学习入口

这里是实习前学习材料的统一入口。阶段目录使用两位数字，并按需求逐步创建，避免为空缺阶段提前铺设大量内容。

```text
learning/
├── stage-00/
│   └── before-learning/   # 已有环境与 CUDA 资料导航
└── stage-01/
    ├── before-learning/   # C++ 与 Linux Runtime 前置讲解
    ├── examples/          # 可编译程序
    └── exercises/         # 待作答练习，不含答案
```

## 学习顺序

1. [主线指南](../Infra%20Introduction.md)：实习前 0–8 阶段与实习后 4 条深化路线。
2. [阶段0](stage-00/README.md)：工具、环境、可信 benchmark 和已有 CUDA 笔记。
3. [阶段1](stage-01/README.md)：面向 CUDA Host 侧开发的 C++ 必需知识，当前阶段。

## 近期路线

```text
阶段0 工具基线
→ 阶段1 C++必需
→ 阶段2 并行基础
→ 阶段3 CUDA核心
→ 阶段4 算子优化
→ 阶段5 框架接入
→ 阶段6 推理量化
→ 阶段7 主线项目
→ 阶段8 投递准备
```

当前只维护阶段 0 和阶段 1 的材料。后续目录在真正进入对应阶段时创建；训推系统、分布式、编译系统和硬件协同不属于实习前必做清单。

旧资料暂不搬动，只在阶段目录中建立索引。这样已有链接仍然有效，新增资料也有固定入口。
