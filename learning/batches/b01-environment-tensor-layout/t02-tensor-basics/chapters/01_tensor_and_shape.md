# 第 1 章：Tensor 与 shape

本章建立后续章节共用的语言：Tensor 是什么、shape 怎么读、怎样创建与改形状。接下来索引、广播和批量矩阵乘法都会先用 shape 描述输入和结果。

## 本节术语与前置知识

- **Tensor**：按轴组织的一组数，例如 `[[10, 20, 30], [40, 50, 60]]`。
- **轴（axis）**：数组变化的一个方向，编号从 0 开始。上面的矩阵有轴 0（行）和轴 1（列）。
- **shape**：每个轴的长度。矩阵 shape 是 `(2, 3)`，合法逻辑坐标为 `(0,0)` 到 `(1,2)`。
- **逻辑坐标/索引**：给每个轴一个从 0 开始的编号。例如 `x[1,2]` 指第二行、第三列，值是 `60`；它不是内存地址。
- **维数**：轴的数量，所以 shape `()` 是 0 维标量，shape `(3,)` 是 1 维向量。

扩展术语见[统一术语表](../../terms.md)。

## 1. Tensor 是什么

Tensor（张量）是带有规则形状的多维数组。可以先把它理解为一组按维度组织的数：

| 例子 | shape | 直观含义 |
|---|---|---|
| `7` | `()` | 一个数，没有轴；这是 0 维 Tensor，也叫标量 |
| `[2, 5, 8]` | `(3,)` | 一条长度为 3 的数列；有 1 个轴 |
| `[[1, 2], [3, 4]]` | `(2, 2)` | 2 行、2 列；有 2 个轴 |
| 由 2 个 `(3, 4)` 矩阵组成 | `(2, 3, 4)` | 2 个矩阵，每个 3 行 4 列；有 3 个轴 |

**shape 里的数字表示每个轴的长度；shape 元组有几个数字，Tensor 就有几个维度。** 因此 `()` 和 `(1,)` 不同：前者是标量，后者是含一个元素的一维 Tensor。

例如，`torch.tensor([[10, 20, 30], [40, 50, 60]])` 有两行三列，shape 是 `(2, 3)`。第 0 轴表示“第几行”，长度为 2；第 1 轴表示“行内第几个数”，长度为 3。shape 描述各轴长度，不是 Tensor 中的具体数值。

![二维 Tensor 的 shape、轴和逻辑坐标示意图](https://fakercodes.oss-cn-hangzhou.aliyuncs.com/sl/t02_shape_axes.svg)

在 PyTorch 中：

```python
import torch

scalar = torch.tensor(3.5)                 # shape=(), ndim=0, numel=1
vector = torch.tensor([2, 5, 8])           # shape=(3,), ndim=1, numel=3
matrix = torch.arange(12).reshape(3, 4)    # shape=(3, 4), ndim=2, numel=12
```

- `x.shape`：每个轴的长度。
- `x.ndim`：轴的个数。
- `x.numel()`：元素总数，等于 shape 中各长度的乘积；标量没有轴长度要相乘，但仍有 1 个元素。
- `torch.arange(n)`：创建包含 `0` 到 `n-1` 的一维序列。
- `reshape(...)`：把元素按原有顺序排成指定形状；新形状的元素总数必须相同。例如 24 个元素可排成 `(2, 3, 4)`，因为 `2×3×4=24`。

具体看 reshape：`torch.arange(6)` 是 `[0, 1, 2, 3, 4, 5]`，shape `(6,)`；执行 `.reshape(2, 3)` 后内容是 `[[0, 1, 2], [3, 4, 5]]`，shape `(2, 3)`。元素没有增减，只是按指定的行列组织。若尝试 `.reshape(4, 2)`，因为原来的 6 个元素无法填满目标 shape 要求的 8 个元素，会报错。

## 2. 读 shape：从左到右给轴命名

看到 `x.shape == (2, 3, 4)`，可依次命名为：

```text
轴 0：长度 2
轴 1：长度 3
轴 2：长度 4
```

shape 本身不说明轴代表“批次、行、列”中的哪一种；含义由数据约定决定。例如 `(batch, rows, columns)` 是一种常见约定。做题时先使用轴编号，只有在矩阵乘法题中再把末两轴解释为行和列。

可以把一个实际的 `(2, 3, 4)` Tensor 想成 2 个小表格，每个表格 3 行、每行 4 个数。`x[0]` 是第一个表格，所以剩 `(3, 4)`；`x[0, 1]` 是第一个表格的第二行，所以剩 `(4,)`；`x[0, 1, 2]` 则是其中一个具体数，所以 shape 为 `()`。
