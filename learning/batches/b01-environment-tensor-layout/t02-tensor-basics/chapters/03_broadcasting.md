# 第 3 章：逐元素运算与广播

## 本节术语与前置知识

- **逐元素运算**：把输入中对齐到同一逻辑坐标的数相加、相减等。例如 `[1,2,3] + [10,20,30]` 得到 `[11,22,33]`。
- **轴长度**：shape 中每一项的数值；`(3,1)` 表示轴 0 长 3、轴 1 长 1。
- **广播**：从最右轴开始比较 shape；两轴长度相等或其中一个为 1 时兼容。长度为 1 表示同一输入元素可供多个输出索引重复使用。
- 较短 shape 缺少的前导轴，在比较时临时按长度 1 处理。例如 `(3,1)` 与 `(1,4)` 按轴对齐后结果 shape 为 `(3,4)`。

扩展术语见[统一术语表](../../terms.md)。

## 4. 广播：逐元素运算时自动对齐形状

逐元素加法会把广播对齐后同一逻辑坐标上的两个元素相加。若输入 shape 不同，PyTorch 会尝试广播：逻辑上把长度为 1 的轴重复使用，使两个输入形状兼容。通常不会先真的复制出完整大数组。

例如，使用具体数字：

![列向量和行向量广播相加得到三行四列结果的示意图](https://fakercodes.oss-cn-hangzhou.aliyuncs.com/sl/t02_broadcasting.svg)

```text
A = [[10],
     [20],
     [30]]         shape (3, 1)

B = [[1, 2, 3, 4]] shape (1, 4)
```

`A + B` 的结果是：

```text
[[11, 12, 13, 14],
 [21, 22, 23, 24],
 [31, 32, 33, 34]]  shape (3, 4)
```

第一轴 `3` 与 `1` 兼容，输出长度取 `3`；第二轴 `1` 与 `4` 兼容，输出长度取 `4`。可以把它想成 A 的每个行值都加到 B 的四个数上。广播让逐元素加法的输入在每组输出逻辑坐标上都能找到对应元素，不需要手动复制 A 和 B。

## 5. 广播的完整判定规则

给两个 shape 做逐元素运算（加减乘除等）时，严格按以下流程判断：

### 规则 A：从最右边的轴开始对齐

把两个 shape 的最右边放在同一列；较短 shape 缺少的前导轴，临时当作长度 `1`。

```text
(5, 3, 1)
(   1, 4)  → 对齐后看作 (1, 1, 4)
```

例如 `A.shape=(5, 3, 1)`、`B.shape=(1, 4)`。B 少了一个前导轴，比较时临时补成 `(1, 1, 4)`；A 和 B 的元素值是什么不影响 shape 判定。

### 规则 B：每一对轴长度必须相等，或其中一个为 1

每一列只有三种兼容情况：

- `a` 与 `a`：兼容，输出该长度 `a`；
- `1` 与 `b`：兼容，输出长度 `b`；
- `a` 与 `b` 且 `a != b`、二者都不为 `1`：不兼容，运算失败。

例如长度为 1 的一行 `[[10]]` 加上长度为 4 的一行 `[[1, 2, 3, 4]]`，得到 `[[11, 12, 13, 14]]`：单个 `10` 在这一轴上供 4 个输出索引重复使用。长度相等时则按相同索引值逐项配对，例如 `[1, 2, 3] + [10, 20, 30] = [11, 22, 33]`。

### 规则 C：输出每一列的兼容长度

```text
(5, 3, 1)
(1, 1, 4)
-----------
(5, 3, 4)
```

缺失的前导 `1` 只用于对齐，不会强迫结果多出一个无意义维度；按列规则得到的完整输出 shape 即 `(5, 3, 4)`。

### 标量为什么能参与任意 shape 的加法

标量 shape 是 `()`，没有轴。例：`torch.tensor(10) + torch.tensor([[1, 2, 3], [4, 5, 6]])` 得到 `[[11, 12, 13], [14, 15, 16]]`，结果 shape 仍为 `(2, 3)`。标量 10 被输出的每个逻辑坐标重复使用。与 `(2, 1, 3)` 相加时，结果同样是 `(2, 1, 3)`；例如全零 Tensor 加标量 10，每个元素都变成 10。

## 6. 怎样解释广播失败

广播失败时，不要只说“shape 不匹配”；需要把维度从右向左对齐，并指出哪一对长度冲突。

```text
(2, 3)
(3, 2)
```

从右侧开始比较：右边是 `3` 对 `2`，两者不相等且都不是 `1`，所以已经失败；左边的比较不再能挽救它。具体来说，左边有 2 行 3 列，右边有 3 行 2 列；逐元素加法需要同一组逻辑坐标上的元素配对，但列轴长度 3 和 2 无法对齐。交换两个 shape 的次序也不会解决问题。

另一个例子：

```text
(2, 3, 4)
(   2, 4)  → (1, 2, 4)
```

最右侧 `4` 对 `4` 可以；中间 `3` 对 `2` 不相等且都不是 `1`，因此不能广播。即使最左侧 `2` 对缺省补出的 `1` 兼容，整组运算仍然失败。

**判定要每一轴都兼容；不是有一轴能扩展就算成功。**
