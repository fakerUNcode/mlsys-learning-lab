## 练习一

阅读代码：

```cpp
std::string_view make_name() {
  std::string name = "cuda";
  return name;
}
```

回答以下问题：

1. 返回后 `string_view` 是否还能安全使用？
2. 用对象生命周期和所有权解释原因。
3. 给出一种安全修改，并说明修改后谁拥有字符数据。

评分：判断 10 分，原因 20 分，修改 20 分，共 50 分。

## 练习二

设计一个 GPU“模型缓存”：多个推理请求可以共享同一组 Device 权重；缓存只观察模型，不应仅因缓存存在就让显存中的旧权重无法卸载。

回答以下问题：

1. 请求侧和缓存侧分别应使用哪种智能指针？
2. 请求取模型时需要进行什么检查？
3. 若 CUDA/PyTorch 扩展被做成 `.so`，说明一个可能的 ABI 风险。
4. 写出构建、运行测试和开启 Sanitizer 的命令。

评分：指针选择 15 分，检查 10 分，ABI 10 分，命令 15 分，共 50 分。
