# 入门测评

本页用于判断是否可以进入第 `01` 节。题目不提供答案；完成后把代码、运行输出和你的解释发来，再逐步批改并评分。

## 前置基础

1. `variant` 表达多种候选状态中的一种。
2. 引用借用已有对象，不取得所有权。
3. 局部对象在作用域结束时自动销毁。

## 第一题

阅读下面的代码，不运行程序，回答问题：

```cpp
std::variant<std::vector<int>, std::string_view> result =
    std::vector<int>{4, 6};

const auto& values =
    std::get<std::vector<int>>(result);
```

1. `result` 当前保存哪个候选类型？
   1. 保存`std::vector< int >`。

2. `values` 是否复制了两个整数？依据是什么？
   1. values没有复制两个整数，在确认result是`<std::vector< int >`后，std::get输出了对result的左值引用给values，values只是result中vector的一个别名。

3. 谁拥有这组整数？
   1. result

4. 若 `result` 先被销毁，之后还能否继续使用 `values`？请解释生命周期关系。
   1. 若result先被销毁，不能继续使用values，即使values的生命周期还没有结束，但他所引用的对象result生命周期已经结束，现在的values是一个悬空的左值引用。


## 第二题

在不修改现有核心函数的前提下，新建一个临时练习程序，完成下面的数据流：

```text
命令行文本
⇒（parse_numbers）解析结果
⇒（成功）打印首元素
⇒（失败）打印错误并返回 2
```

要求：

- 使用 `std::get_if` 判断错误分支；
- 成功后先判断数组是否为空，再读取首元素；
- 用自己的话注释 `string_view` 查看字符的生命周期；
- 用自己的话说明返回码 `0` 和 `2` 分别代表什么；
- 分别运行合法输入与非法输入，保存输出和退出码。
