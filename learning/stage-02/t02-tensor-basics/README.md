# T02：Tensor 创建、索引与广播

## 本记录前置知识

- **shape** 是各轴长度的元组；shape `(2,3,4)` 表示轴 0 长 2、轴 1 长 3、轴 2 长 4。
- **轴编号和索引从 0 开始**；`x[1]` 选轴 0 的第二项。整数索引会让该轴不再出现在结果 shape 中。
- **标量 shape 是 `()`**；它没有轴，但有一个元素。
- **广播**从最右轴开始对齐，缺失的前导轴视作长度 1；两轴等长或其中一轴为 1 时兼容。

更完整的词义见[统一术语表](../terms.md)。

## 学习目标

用形状元组描述 Tensor；预测索引会保留还是移除维度；按末尾维度对齐广播；判断批量矩阵乘法的矩阵维与批次维。
