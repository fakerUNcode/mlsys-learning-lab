# 第 4 章：批量矩阵乘法与 shape 推导

## 本节术语与前置知识

- **矩阵 shape `(M,K)`**：M 行、K 列；与 shape `(K,N)` 相乘时，前者每行的 K 个数和后者每列的 K 个数做点积，结果 shape 是 `(M,N)`。
- **批次轴**：矩阵行列轴之前的轴，用来表示一批矩阵；shape `(B,M,K)` 表示 B 个 `(M,K)` 矩阵。
- **批量矩阵乘法**：末两轴按矩阵乘法规则计算，前面的批次轴按广播规则对齐。例如 `(2,3,4) @ (1,4,5)` 的结果 shape 是 `(2,3,5)`。

扩展术语见[统一术语表](../../terms.md)。

## 7. 矩阵乘法的 shape 规则

二维矩阵乘法：

```text
(M, K) @ (K, N) → (M, N)
```

中间维度 `K` 必须相等：左矩阵每一行有 `K` 个数，才能与右矩阵每一列的 `K` 个数做点积。输出保留左矩阵的行数 `M` 和右矩阵的列数 `N`。

### 带批次维的矩阵乘法

![批次维匹配及末两轴矩阵乘法的 shape 示意图](https://fakercodes.oss-cn-hangzhou.aliyuncs.com/sl/t02_batched_matmul.svg)

对高维 Tensor，**末两轴**仍按矩阵乘法规则处理；**前面的轴**是批次维，需按广播规则兼容：

```text
(batch..., M, K) @ (batch..., K, N)
    → (broadcasted_batch..., M, N)
```

例如：

```text
(2, 3, 4) @ (2, 4, 5)
```

两个输入末两轴 `(3, 4)` 和 `(4, 5)` 符合矩阵规则，得到 `(3, 5)`；前导批次维 `2` 对 `2`，结果仍有两个批次，因此完整结果是 `(2, 3, 5)`。

可以用很小的数字直观看普通矩阵乘法：`[[1, 2, 3]]` 的 shape 为 `(1, 3)`，乘 `[[10], [20], [30]]`（shape `(3, 1)`），结果为 `[[140]]`（shape `(1, 1)`），因为 `1×10 + 2×20 + 3×30 = 140`。中间的 3 必须相同，输出取左侧行数 1 和右侧列数 1。

```text
(7, 2, 3, 4) @ (1, 4, 6)
```

左矩阵批次 shape 是 `(7, 2)`，右矩阵只有一个矩阵，其批次 shape 可看作 `(1)`。从右侧对齐时补成 `(1, 1)`：`(7, 2)` 与 `(1, 1)` 可广播到 `(7, 2)`。矩阵部分 `(3, 4) @ (4, 6)` 产出 `(3, 6)`，完整结果是 `(7, 2, 3, 6)`。

批次维广播的数值小例子：一批有 2 个矩阵，shape `(2, 1, 2)`，分别是 `[[1, 0]]` 和 `[[0, 1]]`；另一个输入只有一个矩阵，shape `(1, 2, 1)`，内容 `[[10], [20]]`。批次维 `2` 对 `1`，所以同一个右侧矩阵分别与两个左侧矩阵相乘，结果 shape `(2, 1, 1)`，内容是 `[[[10]], [[20]]]`。

若矩阵乘法报错，分清两类原因：

1. **矩阵维冲突：** 左矩阵倒数第一维 `K_left` 与右矩阵倒数第二维 `K_right` 不相等。
2. **批次维冲突：** 两边末两轴组成的矩阵维合法，但前导批次维不能按广播规则对齐。

例如 `(2, 3, 4) @ (5, 4, 6)` 的矩阵部分合法：`4` 对 `4`，输出矩阵形状本应为 `(3, 6)`；但批次维 `2` 对 `5`，二者都不为 `1`，所以批量维冲突，整个运算失败。直观上，左边有 2 个矩阵、右边有 5 个矩阵；无法一对一配对，也没有哪一边只有 1 个矩阵可重复使用。

## 8. 每题的可靠推导模板

拿到操作后依次问：

1. 输入分别是什么 shape？先把它们写出来。
2. 操作种类是什么？索引、逐元素运算，还是矩阵乘法？
3. 索引：哪些轴被整数选掉，哪些轴由切片保留？
4. 逐元素运算：从右到左补齐并比较每对长度；输出每一轴长度是多少？
5. 矩阵乘法：先检查末两轴的内维，再单独检查批次维广播。
6. 结论是输出 shape 还是失败？失败时明确冲突轴和长度。

不要只猜输出元素总数。多个不同 shape 可以有相同元素数，只有逐轴推导才能得到正确答案。
