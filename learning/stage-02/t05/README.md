## 一、前置知识：脚本中每种写法都在这里说明

### 1. Python 文件、导入、名字和值

脚本开头：

```python
import torch
import torch.nn.functional as F
DTYPE = torch.float64
STEP = 1e-6
```

- `import torch` 载入 PyTorch 库；之后通过 `torch.xxx` 调用库中的功能。`import torch.nn.functional as F` 取出神经网络函数模块并给它一个较短的名字 `F`，所以 `F.linear(...)` 等价于写完整模块名。
- `=` 把右边的值绑定到名字。`DTYPE` 和 `STEP` 是约定为常量的大写名字：此处分别代表双精度浮点类型和有限差分步长 `0.000001`。Python 并不会因大写而禁止改动它们。
- `1e-6` 是科学记数法，等于 `1×10⁻⁶`。该脚本中的 Tensor 都显式指定 `dtype=DTYPE`，使有限差分在 float64 上计算。

### 2. 函数定义、参数、返回值与类型提示

```python
def twice(value: float) -> float:
    return value * 2
```

`def` 开始定义函数；圆括号里是调用者传入的参数；冒号之后缩进的语句属于函数体。Python 用缩进区分代码块，T05 中 `for`、`with`、函数和 `if` 里的缩进代码都属于对应代码块，不能随意左移或右移。`return` 把结果交回调用处；`-> None` 表示这个函数不返回有用结果。`value: float` 与 `-> float` 是类型提示，帮助读者和工具理解预期类型，但 Python 本身通常不靠这些提示强制类型。

T05 的 `def scalar_loss(x: torch.Tensor) -> torch.Tensor` 接收 Tensor、返回 Tensor。函数调用 `scalar_loss(x)` 会运行函数体并得到返回值。变量名 `loss` 只是普通名字；数学意义由它保存的值决定。

### 3. Tensor：数值、形状、类型与逐元素运算

Tensor 是 PyTorch 保存标量、向量或矩阵数值的对象。`torch.tensor([2.0, -1.0], dtype=torch.float64)` 建立两个元素的一维 Tensor，形状为 `(2,)`。`torch.tensor([[...], [...]])` 建立二维矩阵，形状为 `(2,2)`。所有 T05 数据默认建在 CPU；程序输出会明确打印 `device: cpu`。

在 Tensor 上的 `+`、`-`、`*`、`square()`、`pow(3)` 会按元素或数学运算规则生成新 Tensor。例如 `x.square()` 是每个元素平方，`inner.pow(3)` 是每个元素立方；输入为标量时，结果仍为标量。`.sum()` 将 Tensor 元素相加并产生标量。`.item()` 把只有一个元素的 Tensor 取成普通 Python 数值，便于打印或写入结果。

`dtype=torch.float64` 是给函数传入名为 `dtype` 的参数；`torch.float64` 表示 64 位浮点 Tensor 类型。显式指定类型很重要：数值差分会减去两个相近的损失值，float64 比 float32 保留更多有效数字，但仍有有限精度误差。

### 4. Tensor 形状与线性层的索引

本例 `x` 是形状 `(2,)` 的输入向量，`weight` 是形状 `(2, 2)` 的矩阵，每一行负责一个输出，`bias` 是形状 `(2,)` 的偏置。`F.linear(x, weight, bias)` 的索引定义是：

```text
y[i] = sum over j of W[i,j] * x[j] + b[i]
vector form: y = x @ transpose(W) + b
```

因此输出 `y` 也是形状 `(2,)`。`W[i,j]` 的第一个索引 `i` 选输出行，第二个索引 `j` 选输入列。`target` 与输出形状相同；`residual = output - target` 保存每个输出的误差。平方后求和组成标量损失。代码取 `0.5 * sum(residual * residual)`；系数 `0.5` 会抵消平方求导产生的系数 `2`，因此 `dL/dy[i] = residual[i]`。后面的手算会逐项验证这一点，以及误差如何沿线性层传回输入和参数。

### 5. 自动求导：计算图、叶子 Tensor 与梯度返回值

创建 Tensor 时传 `requires_grad=True`，告诉 PyTorch 要记录它参与的运算。之后执行 `x.square()` 等运算时，PyTorch 除了算出数值，还记录哪些结果由哪些输入算出；这个依赖关系叫计算图。

```python
loss = scalar_loss(x)
(grad_x,) = torch.autograd.grad(loss, (x,))
```

`torch.autograd.grad(output, inputs)` 从输出沿依赖关系反向计算，并按 `inputs` 的顺序返回梯度组成的 tuple。这里 `inputs` 写成 `(x,)`：逗号表示“只有一个元素的 tuple”；括号里的 x 是要对它求导的输入。左边 `(grad_x,)` 是 tuple 解包，把返回 tuple 唯一的梯度取名为 `grad_x`。如果输入多个 Tensor，返回值也按相同顺序排列。

`x` 是叶子 Tensor：它被直接创建并开启梯度跟踪。`loss` 是由运算产生的结果 Tensor。此脚本使用 `torch.autograd.grad` 显式返回梯度，没有调用 `.backward()`，也不会把梯度累积到 `.grad` 字段。

### 6. 中心有限差分：前向取值估计导数

对可微标量函数，在某个坐标 `theta` 附近取两个函数值，中心差分定义为：

```text
g_FD(theta) = (L(theta + h) - L(theta - h)) / (2 * h)
```

`h` 是微小扰动。分子衡量左右两侧的损失变化，除以两点间距 `2*h` 得到局部斜率估计。矩阵或向量求梯度时，逐个坐标单独加减 `h`，其他坐标保持原值。这也叫逐坐标中心差分。它为什么近似导数以及误差从哪里来，会在后面的误差分析中展开。

中心差分不是精确导数。步长较大时，曲线在这段区间内的弯曲会带来约 `O(h²)` 截断误差；步长太小，左右两次计算的损失几乎相同，相减丢失有效数字，舍入误差大致随机器精度除以 `h` 增大。float64 与 `1e-6` 是本次选择的折中，报告误差但不宣称结果精确。

### 7. Python 循环、索引展平、临时修改与恢复

```python
for index in range(parameter.numel()):
    original = parameter.view(-1)[index].item()
```

- `for name in values:` 依次把序列中的值绑定给 `name` 并执行缩进代码。`range(n)` 生成整数 0 到 n-1；Tensor 的 `numel()` 返回元素总数。
- `view(-1)` 把 Tensor 临时看成一维顺序视图；`-1` 表示由 PyTorch 自动推导这一维长度。这里参数是连续存储的普通小 Tensor，因此一维下标 `index` 能逐一访问每个坐标。
- `parameter.view(-1)[index]` 选择一个元素。`.item()` 读出原来的普通数值。把坐标改成 `original + step`、计算损失，再改为 `original - step`、重算损失，之后必须恢复 `original`；否则后续坐标就不再从同一个参数点计算。
- `with torch.no_grad():` 创建一个临时上下文，在缩进块内不记录 autograd 计算图。有限差分只是做前向取值，没有必要记录这些临时图；这也允许在 `requires_grad=True` 的输入上安全地暂时改数值。
- `torch.empty_like(parameter)` 创建形状和类型相同但内容尚未初始化的新 Tensor，脚本随后为每个坐标写入有限差分结果。不可在写入前读取它。

### 8. lambda、闭包与函数参数

```python
loss_fn = lambda: linear_loss(x, weight, bias)
```

`lambda` 定义一个没有显式名字的小函数。冒号左边是参数列表；这里为空，表示调用时不传参数；冒号右侧是返回表达式。这个函数读取当前作用域中的 `x/weight/bias`，这叫闭包。`central_difference` 每次调用 `loss_fn()` 时，函数会用当时被临时扰动的参数重新计算损失。

使用函数而不是把一次算好的 `loss` 传入差分，是因为 `+h` 与 `-h` 都必须重新执行前向计算。

### 9. 断言、误差、格式化输出与检查工具

- `torch.testing.assert_close(actual, expected, rtol=0.0, atol=...)` 比较两个 Tensor 是否在容差内接近；超出就抛异常使程序失败。这里 `rtol=0` 关闭相对容差，只按绝对误差门限核对手算与 autograd、有限差分与 autograd。
- `assert condition, "message"` 是 Python 断言；条件为假时抛出 AssertionError。`==` 比较两个值是否相等并得到 True/False。脚本用断言保证 `gradcheck` 真返回 True，而非只打印一个 False 后仍退出成功。
- `(left-right).abs().max().item()` 先逐元素相减，取绝对值，再选最大差值，最后转为 Python 浮点数。它是最大绝对误差 `max_i |left_i-right_i|`。
- `f"...{value:.3e}"` 是格式化字符串。花括号里插入变量，`.3e` 表示科学记数法并保留 3 位小数；`.12g` 表示最多 12 位有效数字；`{tensor.tolist()}` 把 Tensor 转成普通 Python 列表以清晰打印。
- `for name, manual, automatic, finite in (...)` 会逐行遍历一个由多个 tuple 组成的 tuple，并把每行四个值依次解包到四个名字。这使三个参数组共用一套打印逻辑。
- `torch.autograd.gradcheck(function, inputs, eps=STEP)` 会用数值扰动估计梯度，并和 autograd 产生的梯度逐项比较；`inputs` 必须是可求导的浮点 Tensor。默认容差面向 double 精度。它是数值检查工具，不证明任意输入都正确。

直接运行该文件时，Python 将 `__name__` 设成 `"__main__"`，于是调用 `main()`；若别的 Python 文件导入它，这个条件通常为假，导入只定义函数而不自动开始实验。`main()` 按顺序运行标量和线性层两组检查。

## 二、先独立手算：脚本究竟要验证什么

注意：下面有两个互不相关的例子都把“函数输入”记作 `x`，只是沿用常见符号，并不表示它们是同一个变量。标量复合函数中，`x` 是一个数，本例取 `0.5`；线性层中，`x` 是形状为 `(2,)` 的输入向量，本例取 `[2, -1]`。代码也分别在 `check_scalar()` 和 `check_linear_layer()` 函数内创建各自的局部变量 `x`；两个函数不会传递或共享这个输入。

### 标量复合函数

这个例子是专门构造的平滑数学函数，用来隔离展示“中间结果—外层结果”之间的链式法则；它不是线性层的损失，也不是从训练任务推导出来的。选 `u = x*x + 2*x + 1` 再令 `f = u*u*u`，是因为它有两段容易分别求导的依赖关系，而且在 `x = 0.5` 处各值都能手算。按实际前向顺序计算：

1. 先算中间值：`u = 0.5*0.5 + 2*0.5 + 1 = 0.25 + 1 + 1 = 2.25`。
2. 再算输出：`f = 2.25*2.25*2.25 = 11.390625`。
3. 对中间式逐项求导。幂函数规则是 `d(v^n)/dv = n*v^(n-1)`；常数的导数为 `0`，所以 `d(x*x)/dx = 2*x`、`d(2*x)/dx = 2`、`d(1)/dx = 0`。因此 `du/dx = 2*x + 2`，代入 `x = 0.5` 得 `du/dx = 3`。
4. 外层 `f = u^3` 对 `u` 使用同一幂函数规则，得到 `df/du = 3*u^(3-1) = 3*u*u`。代入 `u = 2.25` 得 `df/du = 3*2.25*2.25 = 15.1875`。
5. 链式法则把两段局部变化率相乘：

   ```text
   df/dx = (df/du) * (du/dx)
         = 15.1875 * 3
         = 45.5625
   ```

相乘的原因是：`x` 先改变 `u`，`u` 再改变 `f`。若 `x` 改变很小的 `dx`，第一段产生 `du ≈ (du/dx)*dx`，第二段产生 `df ≈ (df/du)*du`；代入前一式后，`df/dx` 就是两个局部变化率的乘积。脚本中的 `inner` 对应 `u`，`inner.pow(3)` 对应 `f`，`manual_x` 保存这个手算结果。

### 两输入、两输出线性层

![img](https://fakercodes.oss-cn-hangzhou.aliyuncs.com/sl/linear_layer_forward.svg)

先区分哪些东西由线性层定义，哪些是为了训练或比较梯度而额外选定的目标。线性层只规定如何从输入得到预测值 `y`；它本身不会规定“正确答案”或损失函数。本例把 `target` 数组 `t = [1, 2]` 作为固定目标值，把残差 `r = y - t` 定义为带符号的预测误差，再用平方误差把两个输出的误差合成一个标量目标：

```text
r[i] = y[i] - t[i]
L = 0.5 * sum_i(r[i] * r[i])
```

选择这些定义的原因如下：

- **目标 `t` 是例子给定的数据。** 它不是由 `x`、`W` 或 `b` 算出来的；在真实监督学习里，它对应训练样本提供的标签。本例选 `[1, 2]` 只是为了固定、可复算地演示预测与目标的差异。
- **残差 `r` 是人为定义的误差方向。** 本文约定“预测减目标”，所以正值表示预测高于目标，负值表示预测低于目标。也有人定义“目标减预测”；这会让残差本身反号，但若仍对残差平方，求导时残差反号与它对预测值的导数反号会抵消，最终对预测值和参数的梯度不变。关键是残差定义、损失定义和链式求导使用同一套约定。
- **平方后求和把向量误差变成可微的标量。** `torch.autograd.grad` 和本例的中心差分都针对标量 `L`，而不是直接把两个输出组成的误差向量当作一个普通梯度。平方使正负误差都产生非负惩罚，并让误差较大的坐标贡献更大。
- **系数 `0.5` 是缩放约定。** 对 `r[i]^2` 求导会产生系数 `2`，乘上 `0.5` 后正好抵消，因此 `dL/dy[i] = r[i]`，手算和代码都更简洁。这里有两个输出，所以 `0.5 * sum_i(r[i]^2)` 的数值也恰好等于两项平方的平均值；若输出数量变化，当前写法并不会自动除以输出数量。
- **这是一个教学用回归目标，不是唯一选择。** 改成 `sum_i(r[i]^2)` 会让所有梯度扩大两倍。若改成一般形式的平均平方误差 `sum_i(r[i]^2)/n`，其中 `n` 是输出数，本例 `n=2` 时它与当前 `0.5 * sum_i(r[i]^2)` 数值相同；输出数不为 2 时，两者缩放不同。分类任务还可能使用交叉熵等其他损失。损失改变后，`dL/dy` 也会改变，后续传回 `W`、`b`、`x` 的梯度必须随之重算。

本例固定输入、权重、偏置和目标如下。`W` 的每一行对应一个输出，每一列对应一个输入：

```text
x = [2, -1]
W = [[ 1, 2],
     [-1, 1]]
b = [0.5, -0.5]
t = [1, 2]
```

PyTorch 的 `F.linear` 按 `y = x @ transpose(W) + b` 计算。逐个输出代入：

```text
y[0] = W[0,0]*x[0] + W[0,1]*x[1] + b[0]
     = 1*2 + 2*(-1) + 0.5 = 0.5
y[1] = W[1,0]*x[0] + W[1,1]*x[1] + b[1]
     = (-1)*2 + 1*(-1) + (-0.5) = -3.5
```

因此 `y = [0.5, -3.5]`。残差是输出减目标：`r = y - t = [0.5-1, -3.5-2] = [-0.5, -5.5]`。脚本的标量损失为 `L = 0.5 * sum_i(r[i]*r[i])`，代入得到：

```text
L = 0.5 * ((-0.5)*(-0.5) + (-5.5)*(-5.5))
  = 0.5 * (0.25 + 30.25)
  = 15.25
```

接下来从损失向前求导。先对任意输出 `y[k]` 求导。只有残差 `r[k]` 随 `y[k]` 改变，且 `r[k] = y[k] - t[k]` 的斜率是 `1`。损失中每一项的 `0.5` 与平方导数的 `2` 抵消：

```text
L = 0.5 * sum_i (y[i] - t[i])^2
dL/dy[k] = 0.5 * 2 * (y[k] - t[k]) * 1
          = r[k]
```

这说明上游传给线性层的梯度向量就是 `r`。再分别看三个输入组：

1. **偏置 `b[k]`：** 先看它如何进入输出：`y[i] = sum_j(W[i,j]*x[j]) + b[i]`。因此改动 `b[k]` 只会改动第 `k` 个输出：`dy[k]/db[k] = 1`；对其他输出 `i != k`，`dy[i]/db[k] = 0`。

   求和号来自多变量链式法则：`L` 是一个标量，但它同时把整个输出向量 `y`（本例有 `y[0]` 和 `y[1]`）作为输入。改变 `b[k]` 后，要把它经过每个 `y[i]` 传到 `L` 的变化率都加起来。每条路径的变化率是“损失对该输出的变化率”乘“该输出对这个偏置的变化率”。所以先写成对所有输出路径求和，再代入 `dL/dy[i] = r[i]`：

   ```text
   dL/db[k] = sum_i ((dL/dy[i]) * (dy[i]/db[k]))
            = sum_i (r[i] * (1 if i == k else 0))
            = r[k]
   ```

   本例有两个输出，逐项看这个求和：

   ```text
   k = 0: dL/db[0] = r[0]*1 + r[1]*0 = -0.5
   k = 1: dL/db[1] = r[0]*0 + r[1]*1 = -5.5
   ```

   因为各偏置只影响自己的输出，求和中的其他路径都乘以 `0`，最后只剩 `r[k]`。若某层让多个输出共同依赖同一个偏置或输入，多个路径就可能都非零，必须把它们相加。

   ![偏置独立 vs 共享输入的反向传播路径求和对比示意图](https://fakercodes.oss-cn-hangzhou.aliyuncs.com/sl/gradient_path_sum.svg)

   也可以直接看第 `k` 项：`0.5 * (y[k]-t[k])^2` 对 `b[k]` 求导时，平方的 `2` 与损失前的 `0.5` 抵消，且 `dy[k]/db[k]=1`，所以仍得到 `y[k]-t[k]=r[k]`。本例 `k=0` 时结果为 `r[0]=-0.5`，`k=1` 时为 `r[1]=-5.5`，故 `dL/db=[-0.5,-5.5]`。它与 `b` 形状相同，因为每个输出各有一个独立偏置。

2. **权重 `W[k,j]`：** 这里 `W[k,j]` 表示矩阵 `W` 第 `k` 行、第 `j` 列的一个标量元素；它不是整行。若要表示第 `k` 行全部权重，写作 `W[k, :]`。由于 `W` 的每一行对应一个输出，第 `k` 行 `W[k, :]` 正是计算输出 `y[k]` 时乘输入向量各分量的权重。由 `y[i] = sum_l(W[i,l]*x[l]) + b[i]` 可见，单个元素 `W[k,j]` 只会出现在 `y[k]` 的一项 `W[k,j]*x[j]` 中；对这个权重求导，该项的导数是它的系数 `x[j]`，其他输出对它的导数为 `0`：

   ```text
   dy[i]/dW[k,j] = x[j]  if i == k
                 = 0     if i != k
   ```

   沿所有输出路径使用链式法则，只有 `i == k` 的项留下：

   ```text
   dL/dW[k,j] = sum_i ((dL/dy[i]) * (dy[i]/dW[k,j]))
              = r[k] * x[j]
   ```

   因此每个权重梯度是“该输出的误差”乘“该输入分量”。

   ![W[k, j] 标量元素与 W[k, :] 整行的区分示意图](https://fakercodes.oss-cn-hangzhou.aliyuncs.com/sl/weight_notation.svg)

   逐元素展开外积：

   ```text
   dL/dW[0,0] = r[0]*x[0] = (-0.5)*2  = -1
   dL/dW[0,1] = r[0]*x[1] = (-0.5)*(-1) = 0.5
   dL/dW[1,0] = r[1]*x[0] = (-5.5)*2  = -11
   dL/dW[1,1] = r[1]*x[1] = (-5.5)*(-1) = 5.5
   dL/dW = [[-1, 0.5],
            [-11, 5.5]]
   ```

   在代码记法 `r[:, None] * x[None, :]` 中，`r` 原形状是 `(2,)`；`[:, None]` 在末尾增加一维，成为 `(2, 1)`。`x[None, :]` 在开头增加一维，成为 `(1, 2)`。逐元素乘法按广播规则把二者扩展到共同形状 `(2, 2)`：第 `(i,j)` 格正好是 `r[i]*x[j]`，因此行索引仍对应输出 `i`，列索引仍对应输入 `j`，与 `W` 的存储布局一致。脚本将这四个手算值写入形状 `(2,2)` 的 `manual_weight`，然后与 autograd 和有限差分比较。

3. **输入 `x[j]`：** 要先从线性层定义推出它对输出的斜率。固定某个输出 `y[i]`：

   ```text
   y[i] = W[i,0]*x[0] + W[i,1]*x[1] + ... + W[i,j]*x[j] + ... + b[i]
   ```

   对 `x[j]` 求导时，只有含 `x[j]` 的那一项会变化；`W[i,j]` 是乘在 `x[j]` 前面的常数，其他输入项和偏置都不随 `x[j]` 改变。因此：

   ```text
   dy[i]/dx[j] = W[i,j]
   ```

   例如本例的权重矩阵给出四条局部变化关系：`dy[0]/dx[0] = W[0,0] = 1`、`dy[1]/dx[0] = W[1,0] = -1`、`dy[0]/dx[1] = W[0,1] = 2`、`dy[1]/dx[1] = W[1,1] = 1`。也就是说，`x[0]` 增加一个很小的量时，`y[0]` 同量增加、`y[1]` 同量减少；`x[1]` 的变化则分别按 `2` 倍和 `1` 倍传给两个输出。

   下面每条箭头上的数是该边的局部导数。输入改变会沿多条路径到达损失，所以每条路径的贡献都要相加：

   ```text
   x[0] -- W[0,0]=1  --> y[0] -- dL/dy[0]=r[0]=-0.5 --> L
   x[0] -- W[1,0]=-1 --> y[1] -- dL/dy[1]=r[1]=-5.5 --> L
   x[1] -- W[0,1]=2  --> y[0] -- dL/dy[0]=r[0]=-0.5 --> L
   x[1] -- W[1,1]=1  --> y[1] -- dL/dy[1]=r[1]=-5.5 --> L
   ```

   对固定的输入分量 `x[j]`，多变量链式法则把所有输出路径相加：

   ```text
   dL/dx[j] = sum_i ((dL/dy[i]) * (dy[i]/dx[j]))
            = sum_i (r[i] * W[i,j])
   ```

   本例将 `j=0` 和 `j=1` 分别代入：

   ```text
   dL/dx[0] = r[0]*W[0,0] + r[1]*W[1,0]
            = (-0.5)*1 + (-5.5)*(-1) = 5
   dL/dx[1] = r[0]*W[0,1] + r[1]*W[1,1]
            = (-0.5)*2 + (-5.5)*1 = -6.5
   dL/dx = [5, -6.5]
   ```

   矩阵写法是 `transpose(W) @ r`。转置后 `W` 的每一行代表某个输入在各输出中的系数，因此矩阵乘法会沿输出索引求和。

汇总结果并核对形状：

| 梯度 | 结果与形状 | 含义 |
| --- | --- | --- |
| `dL/db` | `[-0.5, -5.5]`，形状 `(2,)` | 每个输出自己的误差 |
| `dL/dW` | `[[-1, 0.5], [-11, 5.5]]`，形状 `(2, 2)` | 每个输出误差乘对应输入值，布局和 `W` 相同 |
| `dL/dx` | `[5, -6.5]`，形状 `(2,)` | 对每个输入累加两个输出分支的贡献，即 `transpose(W) @ r` |

这些形状分别与脚本创建的 `bias`、`weight`、`x` 一致。PyTorch 的 `torch.autograd.grad(loss, (x, weight, bias))` 也按这个顺序返回三组梯度；手算张量因此可以逐元素与自动求导结果比较。

图示执行顺序：

```text
前向：x ──线性层(W,b)──> y ──与 target 比较──> 标量损失 L
反向：x <──累加各输出路径── W,b <── r=y-target <── L
数值检查：每次只改 x/W/b 的一个坐标 +h、-h，各跑一次前向，再用损失差除以 2h
```

## 三、从上到下读 verify_gradients.py

### 1. 固定配置和 `scalar_loss`

`DTYPE=torch.float64`、`STEP=1e-6` 是脚本共享的数值设置。`scalar_loss(x)` 先按 `inner=x.square()+2*x+1` 计算 u，再返回 `inner.pow(3)`。它对标量 Tensor 返回标量 Tensor；函数只描述前向公式，PyTorch 会因 x 开启梯度跟踪而记录依赖。

### 2. `central_difference`：逐元素估计梯度

参数 `loss_fn` 是每次调用都会重新算出标量损失的函数；`parameter` 是要对其求偏导的 Tensor；`step` 是扰动步长。函数创建与参数同形状的 `estimate`，随后进入 `no_grad` 区域。

循环对每个展平坐标执行相同的顺序：保存原值 → 写 `原值+h` 并计算 `plus` → 写 `原值-h` 并计算 `minus` → 恢复原值 → 把 `(plus-minus)/(2h)` 写入结果 Tensor 同一位置。循环结束时 `estimate` 与输入形状一致，每个位置保存对应偏导数估计。调用方传入的参数值已恢复，不会停留在最后一次扰动点。

此函数假设前向确定且无副作用、损失是单个实数、输入 Tensor 连续。遇到异常时当前实现不会用 `finally` 恢复坐标；本题的固定前向不触发异常，生产级通用工具需另外保证异常路径也恢复输入。

### 3. `max_abs_error`

输入是同形状的两个梯度 Tensor；返回最大坐标差绝对值。若一个梯度完全吻合，返回 0。它只汇总误差，不判断是否通过；检查阈值由 `torch.testing.assert_close` 另行执行。

### 4. `check_scalar`

先构造值为 0.5、`requires_grad=True` 的标量 x，计算前向 loss，再用 `torch.autograd.grad` 得到 `autograd_x`。手算结果保存到 `manual_x`。传入 lambda 作为差分函数，让 `central_difference` 在每次扰动之后重新调用 `scalar_loss(x)` 得到 `finite_x`。

两条 `assert_close` 分别要求 autograd 与手算在 `1e-12` 绝对误差内吻合、有限差分与 autograd 在 `1e-7` 内吻合。接下来打印损失、三种梯度和实测误差。`x.detach()` 产生不连接原计算图的 Tensor，`.requires_grad_()` 在这个新 Tensor 上原地开启梯度跟踪；把它送进 gradcheck 可重新检查函数本身。

### 5. `linear_loss` 与 `check_linear_layer`

`linear_loss(x, weight, bias)` 每次创建固定目标 `[1,2]`。这个目标是教学样本提供的常量，不是线性层的输出；函数先按 `F.linear` 产生预测，再用“预测减目标”定义残差，最后返回 `0.5` 倍的平方和。半平方和把两维误差压成一个标量，适合本例的普通梯度对照，而 `0.5` 让输出梯度恰好等于残差。换用别的目标或损失都会改变损失值和梯度，不会改变 `F.linear` 的前向定义。

`check_linear_layer` 用指定的 x/W/b 建立可求导叶子 Tensor。`torch.autograd.grad(loss, (x, weight, bias))` 按 tuple 顺序返回三个梯度，左侧三个名字依序接收它们。接着把手算梯度写成同 dtype Tensor；lambda 关闭在 x/W/b 这些名字上，每次都调用同一个 `linear_loss`。中心差分依次扫描 x、weight、bias，每次扫描结束都会恢复该参数。

第一个 `for` 循环将手算、autograd、有限差分三组梯度一一配对，确保手算与 autograd 误差不超过 `1e-12`，有限差分与 autograd 误差不超过 `1e-7`。第二个循环遍历 `("dx", ...), ("dW", ...), ("db", ...)` 三个记录，打印三套数值和每组最大误差。最后 gradcheck 重新创建独立的可求导输入 tuple；若返回 False，显式断言会让进程以异常失败。

### 6. `main` 与运行顺序

运行文件底部的入口判断后，`main()` 先打印 PyTorch 版本、dtype、步长和 CPU 设备，再依次调用 `check_scalar()` 与 `check_linear_layer()`。任何数值断言或 gradcheck 失败都会中止程序并给出错误；全部完成且两个 gradcheck 为 True 才是成功运行。

## 四、差分误差与不可导点

在平滑区域，中心差分为什么有 `h²` 阶截断误差，可以从 `theta` 附近的 Taylor 展开看出。下面写到四阶项并将余项记为 `O(h^5)`，假设 `L` 在该点附近至少五次连续可导：

```text
L(theta + h) = L(theta) + h*L'(theta) + h^2/2*L''(theta)
               + h^3/6*L'''(theta) + h^4/24*L''''(theta) + O(h^5)
L(theta - h) = L(theta) - h*L'(theta) + h^2/2*L''(theta)
               - h^3/6*L'''(theta) + h^4/24*L''''(theta) + O(h^5)
```

用第一行减第二行，偶数次项 `L(theta)` 和 `h^2*L''(theta)/2` 抵消；再除以 `2*h`：

```text
(L(theta+h) - L(theta-h)) / (2*h)
= L'(theta) + h^2/6 * L'''(theta) + O(h^4)
```

相减后，四阶导数项也抵消；两个余项相减后除以 `2*h` 仍是 `O(h^4)`，而三阶导数项留下 `h²/6` 系数。因此主要截断误差随 `h²` 缩小。实际浮点计算还要注意另一项误差：`h` 太小时，两次损失值非常接近，相减会丢失有效位，舍入误差大致随机器精度除以 `h` 增大。减小 `h` 起初会降低截断误差，继续减小则可能让舍入误差占主导。要结合 dtype、函数数值尺度与输入位置报告步长和误差；`1e-6` 不是通用最佳步长。

ReLU 定义为 `ReLU(x) = max(0,x)`。当 `x < 0` 时它恒为 `0`，斜率是 `0`；当 `x > 0` 时它等于 `x`，斜率是 `1`。在 `x=0`，左边斜率 `0` 与右边斜率 `1` 不相等，所以普通导数不存在。取 `h > 0`，零点的中心差分左右函数值分别是 `ReLU(h)=h`、`ReLU(-h)=0`，代入得到：

```text
(ReLU(h) - ReLU(-h)) / (2*h)
= (h - 0) / (2*h)
= 0.5
```

PyTorch 对 ReLU 零点采用反向梯度约定 `0`。因此在这个非光滑点，中心差分的 `0.5` 与框架选择的 `0` 不同；这来自“普通导数不存在”与“框架需要为反向传播选一个值”的区别，不能据此断言实现必错。应该在可微输入点做 gradcheck，并把非光滑处的约定单独说明。
