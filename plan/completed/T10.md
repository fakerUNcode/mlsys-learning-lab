## 产物与验证

- 笔记、CPU/GPU 实验、测试与报告：见 [T10 验证报告](../../reports/stage-02/2026-10-12-t10-validation.md)。
- 环境：仓库 `.venv`、PyTorch 2.11.0+cu128；CPU 与 NVIDIA GeForce RTX 5080 Laptop GPU（CUDA 12.8）；数值 dtype 为 float64；无随机输入。
- 命令：
  - `.venv/bin/python learning/batches/b03-attention/t10-numerical-stability-and-attention-cost/attention_cost.py`
  - `.venv/bin/python learning/batches/b03-attention/t10-numerical-stability-and-attention-cost/test_attention_cost.py`
- GPU 命令：
  - `.venv/bin/python learning/batches/b03-attention/t10-numerical-stability-and-attention-cost/attention_cost_gpu.py`
  - `.venv/bin/python learning/batches/b03-attention/t10-numerical-stability-and-attention-cost/test_attention_cost_gpu.py`
- 结果：CPU/GPU 上朴素 softmax 对 `[1000,999,998]` 均输出 NaN；减最大值后均输出有限概率 `[0.6652409558, 0.2447284711, 0.0900305732]`；CPU/GPU 全 mask 行均返回 `[0,0]`；CPU 5 项 unittest 与 CUDA 2 项 unittest 全通过。
- 资源账：B=1、H=16、d=64、fp16；S 翻倍 4096→8192 后每份 score/probability 为 512 MiB→2 GiB，完整展开 bool mask 为 256 MiB→1 GiB，Q/K/V/O 合计为 32→64 MiB，每层 KV cache 为 16→32 MiB，两次矩阵乘法 FLOPs 为 68,719,476,736→274,877,906,944。
- 完成接受标准：减最大值效果、全 mask 行定义、序列翻倍的平方/线性项、FlashAttention 减少的 HBM 读写均在笔记与 CPU/GPU 实测输出中对应；GPU 路径是 PyTorch CUDA Tensor reference，未实现完整 CUDA/Triton kernel。

## 能力与限制

- 明确全 mask 行按本 reference 约定输出零概率与零注意力加权输出；残差路径仍可能保留输入。
- FlashAttention 数学上计算精确 Attention，但不同浮点归约次序不承诺逐位相同；本任务未实测真实 FlashAttention 后端。
- 资源表是公式估算，不包含投影、反向保存张量、临时工作区、分配器碎片或实际 mask 广播方式。
- GPU 只验证 CUDA float64 小张量；没有验证 GPU fp16/bf16 数值、反向传播、峰值显存或性能。
- 独立复写及口述理解尚未验收，程序自动检查不作为个人掌握证据。
