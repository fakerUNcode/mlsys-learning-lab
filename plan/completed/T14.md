## 结果

- 固定数据两条完整序列 shape `[2,5]`；输入与标签分别为 `[2,4]`，标签对应输入右移一个 token。
- T13 模型宽度 8、4 个查询头、2 个 KV 头、前馈宽度 12、词表 6；logits shape `[2,4,6]`，参数量 600。
- CPU float32、seed 1415、AdamW learning rate 0.02；33 步后最终平均交叉熵 `0.00848716`（阈值 `<0.01`），8/8 token 的 argmax 与标签相同。
- 两个前缀的 greedy 生成分别得到 `[0,3,4,5,2]` 和 `[1,5,4,3,2]`，追加 EOS 后停止。采样轨迹固定 seed 也可重放。
- `.venv/bin/python .../test_t14.py`：5 项测试通过。训练临时设置 CPU 单线程并在返回时恢复调用者原有线程数。环境 Python 3.12.3、PyTorch 2.11.0+cu128；CUDA 可用但本任务只在 CPU 运行。

## 过程记录

首次训练运行失败并及时暴露数据设计冲突：两个样本共用相同起始 ID，却对同一上下文要求不同的下一 token，无法同时过拟合。随后为两条序列分配不同起始 ID，重新训练并通过损失和 token 级断言。失败版本没有作为正确性证据保留；原因和修正写入 T14 验证报告。
