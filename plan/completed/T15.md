## 结果

- Python 3.12.3、PyTorch 2.11.0+cu128；CPU float64，seed 1515；配置 `V=17,D=8,Hq=4,Hkv=2,d=2,F=12`，单 block。
- Prompt 长度 1、3、5；各执行一次 prefill 和 16 次单 token decode；共 51 个 prefill/当前位置 logits 对照。
- `rtol=0, atol=1e-12` 下全部通过；最大绝对误差 `2.220446049250313e-16`。
- 长度依次为 `P` 到 `P+16`；旧 cache 不被修改。测试 2 项通过。
- K 缓存为已做 RoPE 的 key；V 缓存为原投影 value。Q 是当前步临时张量，不用于未来步。

## 验收映射

| 要求 | 证据 |
| --- | --- |
| 至少 3 种 prompt 长度与连续 16 步 logits 对齐 | 长度 1/3/5，各 16 步；逐 token 向量对比与最大误差在报告、JSON 与测试中 |
| 缓存长度不重复增长 | 每一步期望长度断言；独立检查旧缓存仍保持原内容和长度 |
| 覆盖 prefill 与单步 decode | `past=None` 时处理完整 prompt；已有 cache 时严格只接受一个新 token |
| 解释只缓存 K/V | 章节和报告说明旧 Q 不复用、历史 K/V 被所有后续 Query 读取；明确 K 存储 RoPE 后状态 |
