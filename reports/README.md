## 文件约定

```text
reports/
├── README.md
├── stage0_environment.md        # 旧报告，保留路径
├── stage-01/
│   ├── README.md                # 阶段索引
│   └── <NN>-<chapter>.md        # 分章报告
├── stage-<NN>/
│   └── <YYYY-MM-DD>-<topic>/    # 后续复杂实验可独立建目录
├── figures/
└── data/
```

图表和小型结果摘要可以提交。大型 profiler 输出、模型权重和可再生成的构建产物应存放在外部 artifact，并在报告中记录获取方法。

## 报告模板

```markdown
# 实验名称
## 问题
## 假设
## 环境
## 方法
## 正确性
## 性能
## 分析
## 局限
## 结论
## 复现
```

至少记录 Git commit、完整命令、输入参数、随机种子、GPU、驱动、CUDA、PyTorch、编译器、warmup、采样次数和统计方式。

## 证据要求

- 原始数据与正文数字能够对应。
- baseline 和候选版本使用相同实验条件。
- 失败实验也记录原因，避免重复走弯路。
- 区分观测事实、基于证据的推断和仍需验证的猜想。
- 结论注明适用的硬件、shape、dtype 和软件版本范围。
