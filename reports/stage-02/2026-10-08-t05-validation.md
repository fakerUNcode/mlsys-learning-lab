## 数值结果

| 问题与参数 | 手算 / autograd | 中心有限差分（h=1e-6） | 最大绝对误差 `|FD-autograd|` |
| --- | --- | --- | ---: |
| 标量 `df/dx` | `45.5625` | `45.5624999995` | `4.592e-10` |
| 线性层 `dL/dx` | `[5, -6.5]` | `[5.000000001587068, -6.500000001352646]` | `1.587e-9` |
| 线性层 `dL/dW` | `[[-1, 0.5], [-11, 5.5]]` | `[[-0.9999999992515995, 0.4999999996257998], [-11.000000001537558, 5.500000001212868]]` | `1.538e-9` |
| 线性层 `dL/db` | `[-0.5, -5.5]` | `[-0.4999999996257998, -5.500000001212868]` | `1.213e-9` |

标量例子 `f(x)=(x²+2x+1)³` 在 `x=0.5`；线性层为 `y=xWᵀ+b`，损失 `L=0.5Σ(y-t)²`，固定 `x=[2,-1]`、`W=[[1,2],[-1,1]]`、`b=[0.5,-0.5]`、`t=[1,2]`。报告中的梯度可由脚本逐项输出复现。

两次 `torch.autograd.gradcheck(..., eps=1e-6)` 均返回 `True`。这是同一点上有限差分与 autograd 结果符合检查容差的证据；不是对所有输入、所有 dtype 或自定义算子实现的证明。

## 误差与不可导点

中心差分用 `h` 和 `-h` 两侧的函数值估计导数。步长较大时，局部曲率使有限间隔的斜率偏离点导数，主导截断误差通常为 `O(h²)`；步长极小时，两侧函数值过于接近，相减会放大浮点舍入误差，量级可粗略理解为机器精度除以 `h`。所以本次选用 float64 与 `1e-6`，并按数值结果报告误差，而不是宣称有限差分是精确值。

ReLU 在 0 的左右导数不同，不存在普通导数。对称中心差分会得到 `0.5`，PyTorch 的 ReLU 反向约定在 0 取 `0`；`gradcheck` 在非光滑点可能失败，失败本身不足以证明反向公式错误。数值梯度检查应优先在可微点执行，并单独记录分段边界使用的约定。

## 覆盖和限制

| 项目 | 证据 / 边界 |
|---|---|
| 链式法则 | 手算复合函数各层局部导数并连乘，与 autograd 对照 |
| 线性层参数梯度 | 对输入、权重、偏置每个坐标做扰动；形状和索引与手算公式一致 |
| 数值方法 | float64 中心差分、固定 `1e-6` 步长、记录逐组最大绝对误差 |
| gradcheck | 标量与线性层检查都通过；函数输出为实数标量，参数无重叠存储 |
| 不可导行为 | 文档给出 ReLU 零点的左右导数、中心差分结果及 PyTorch 约定；没有把该点当作平滑函数的 gradcheck 样本 |
| 未覆盖 | 随机输入、更多步长扫描、GPU/低精度、非标量输出 Jacobian、独立推导验收 |

脚本的 `central_difference` 临时修改一个输入坐标，分别计算 `+h` 与 `-h` 的损失，然后恢复原值；它适用于本题独立、无副作用的确定性前向函数。若函数含随机性、状态更新或不可逆副作用，需先固定/隔离这些因素，不能直接套用本实现。
